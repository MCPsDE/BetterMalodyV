# BetterMalodyV

让选曲更顺手。这里列出插件当前提供的全部优化与修改。

## 按谱面状态筛选

在大厅与联机房间的高级搜索中，搜索输入框内部右侧新增 Stable、Beta、Alpha 勾选框和 All（全部）按钮。左侧仍可输入关键词，等级、BPM、时长筛选保留原有位置。

- **Stable**：仅显示包含 Stable 谱面的歌曲；进入歌曲后仅显示 Stable 谱面。
- **Beta**：仅显示 Beta 谱面，以及包含这些谱面的歌曲。
- **Alpha（含 Promotion）**：同时包含普通 Alpha 和 Promotion Alpha。推荐属性没有独立的本地状态值。
- 可以同时勾选多个状态，结果为所选状态的并集；不勾选任何状态时结果为空。
- 默认全部勾选，保留原有全部谱面，包括尚未确认状态的谱面。「全部」可随时恢复默认。
- 与原有关键词、等级、BPM、时长、收藏夹及模式筛选一起使用。所选游戏模式需要同一张谱面满足状态条件。
- 筛选条件保存到本地，重新启动游戏后仍然有效。大厅与联机房间共享该条件。

筛选依据是游戏已经缓存的本地状态，无需联网。尚未缓存或已经过期的状态不会被猜测成 Stable；游戏正常更新本地状态后，以新缓存为准。

## 安装与桌面入口

- 离线安装器自动寻找 Steam 游戏目录，也支持手动选择。
- 复用兼容的 BepInEx 6 IL2CPP；没有运行环境时安装随附版本。
- 安装完成后创建「BetterMalodyV 管理面板」桌面快捷方式。
- 支持修复和卸载，保留用户修改过的文件；兼容与 MalodyVThemeLoader 共存。

## 管理面板

- 本页面直接读取 Markdown 文档，支持标题、段落、列表、粗体和链接。
- 文档保存后自动重新加载；按 F5 也可以手动刷新。
- 支持浅色与深色外观，并提供「赞助支持」入口。

## 自动更新

- 打开管理面板时检查 GitHub 的正式 Release，也可以手动检查。
- 发现新版后下载对应安装器，核对 SHA-256，关闭面板后执行更新。
- 更新完成后重新打开面板；游戏中的插件在下次启动游戏时加载新版。
- 检查失败时仍可正常阅读和使用已安装版本，稍后可重新检查。
