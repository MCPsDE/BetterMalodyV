修复只勾选 Stable 等状态时，大曲库可能导致游戏长时间无响应的问题；三个状态标签改为半透明灰色。

- 原因是旧版在歌曲筛选循环中调用 ScanFiles，在主线程和显示列表写锁内遍历全库目录、加载与解析谱面。
- 改为后台读取本地数据库副本建立状态索引，未加载歌曲仅查询内存摘要。已打开歌曲读取当前内存状态，进入歌曲后仍按实际谱面过滤。
- 后台缓存完成或变化后自动刷新结果，保留关键词、模式等原有过滤。
- Stable、Beta、Alpha 使用半透明灰色标签，以勾选标记区分状态，位置仍在搜索框内部右侧。
